# 网站审查：自 0.13.4（6a04c24）以来的改动（2026-11-26）

维护者：“检查网页端是否适配最新版终端和旧版终端，并且确认网页端各功能是否完成收尾，做审查”。之后网站暂不部署（“先不推送这份网页端了”）。

**检查方式**：

- 本机运行 6a04c24 的旧服务端，用旧格式快照模拟 0.13.6 终端，让新网站连接它；
- 另由一个独立审查代理通读 `public-site/` 自 6a04c24 以来的全部改动和未提交改动。

编号 W1～W2 由我在旧服务端上实测，或在代码中复核；其余为审查代理读代码得出，未逐条复核。

## 已修复

- **W0 账户对话框里操作失败时没有任何提示**（0.13.4 起就有）。
  - 原因：`finishQueueCommand` 写入错误后立即刷新，刷新一开始就把错误清空。
  - 已改为刷新完成后再写入错误。

## 审查确认没有问题的

- 勾选框和一对机台的操作只在服务端给出一对机台时出现，旧服务端、旧终端不会触发。
- 快照缺少新字段时都有安全的默认值。
- 网站调用的接口在旧服务端上都存在；提交的内容符合新服务端的校验。
- 没有遗留的 TODO 或调试代码。
