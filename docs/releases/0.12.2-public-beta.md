# maimai Q 0.12.2 公开测试版

maimai Q 0.12.2 收尾跨端操作反馈与安全刷新。部署者仍可使用自己的服务器、域名、数据库、网站和 QQ Bot，不依赖项目维护者服务器。

> 本版本仍处于 `0.x` 测试阶段。真实现场更新前应先备份终端数据和服务端 SQLite，并完成网站、Bot、终端与移动设备登记的联调。

## 本次更新

- 网页登录玩家的“我的排队”使用明确状态徽标，区分正常排队、暂缓一次、暂时离开、待签到、正在游玩、机台停止使用和状态待更新。
- 网站会保留最近三条操作结果约 10 秒，玩家可随时关闭。成功结果显示现场终端实际返回的内容。
- 远程操作提交失败、现场拒绝或结果读取超时时，页面提供“刷新最新状态”。该入口只读取权威队列和玩家资料，绝不会自动重复退出排队、暂缓一次、暂时离开、转机台或修改本次偏好等风险命令。
- 终端、网站和 QQ Bot 继续统一动作结果、数据更新时间、同步状态和离线原因的文案；Bot 在不能完成操作时说明下一步可使用的“加入排队”、“我的排队”或“查看队列”。
- 闭店收尾、正常轮换、暂缓一次、暂时离开、待签到、固定组合、共同游玩预览、估时和机台容量规则均未改变。估时说明展开与队列分享不包含在本版本。

## 下载文件

- `maimai-Q-0.12.2-terminal-beta.apk`：连接自建服务端的现场终端版。没有预置服务端地址或令牌，安装后由机厅管理员配置。
- `maimai-Q-0.12.2-local-beta.apk`：完全离线版，不申请联网权限，不提供网站或 Bot 同步。
- `public-site-0.12.2-beta.tar.gz`：独立公开队列页与网页玩家资料的静态文件。
- `koishi-plugin-maimai-q-0.3.13.tgz`：本版本配套的 Koishi 插件。
- `SHA256SUMS-0.12.2.txt`：全部发布附件的 SHA-256 校验值。

两个 APK 均使用既有 maimai Q 长期发布证书签名。证书 SHA-256 指纹：

```text
daa2e919d2f8d956c0a93417aae601e6ec658edc5ae7c9673830c53f649ec925
```

Release APK 与 Debug 联调包签名不同，不能直接互相覆盖。已经安装 0.10.1 或更高公开测试 Release 的设备可以保留数据覆盖升级；从 Debug 包迁移前应先保存数据并停止现场排队。

## 部署与更新

服务端、网站、Bot 和终端必须使用同一 Release。推荐更新顺序为服务端、网站、Bot、终端；每一步完成后再检查 `/queue-api-healthz`、网站版本详情、Bot 查询和终端同步。

服务端从固定 Tag 的 `cloud-server/` 构建，网站直接解压静态附件，Bot 直接安装 `.tgz`。完整步骤见[公开测试版自建部署方案](../public-beta-deployment.md)。更新前必须备份 SQLite、`.env`、反向代理配置、Bot 配置、网站目录和终端数据。

## 验证范围

- 服务端 144 项测试、Koishi Bot 80 项测试、Android 应用与队列核心单元测试全部通过。
- 独立公开网站和复用队列组件的网站构建通过，共享组件一致性检查通过。
- 浏览器行为测试覆盖网页登录后打开本人登记、提交退出排队，以及待签到登记关闭再打开后的状态恢复。
- Release APK 已核对版本号、应用 ID、联网权限、非 Debug 标记、长期签名证书，以及空的内置服务端地址和令牌。

## 已知边界

- 一个服务端实例仍只支持一个活动机厅和一台权威写入终端；多机厅与多终端同时联动尚未开放。
- 忘记网页密码时不允许在公共终端直接重置，当前需由管理员线下核验处理。
- 网站只能管理当前登录资料对应的本人登记，不能远程签到、结束本轮、调整他人登记、拖动顺序或修改终端设置。
- 当前不提供预构建 Docker 镜像，API 仍由部署者从固定 Tag 构建。
