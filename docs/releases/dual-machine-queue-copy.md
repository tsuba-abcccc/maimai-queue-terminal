## 三、说明弹窗

首次使用时自动弹出（临时登记每次，每份玩家资料一次），五秒后才能关闭；点问号打开时内容相同，不倒计时。

第 11 条的正文：

1. 开启后，这份登记仍在当前机台排队。
2. 机台 B 能够更早安排这份登记游玩时，登记自动转至 机台 B 并进入游玩位置。请留意现场提示和通知。
3. 游玩一轮之后，登记将保留在上次游玩的机台，这项功能保持开启。
4. 以下情况，登记不会被安排到另一机台：
   - 暂缓一次、暂时离开和待签到期间。
   - 等待顺序被调整、登记从游玩位置撤回，或为已经在排队的登记开启之后，直到这份登记游玩一轮。
   - 固定组合。
5. 机台 B 能够更早安排这份登记游玩时，其等待顺序中会显示预览。可以随时在“更改游玩偏好”中取消。
