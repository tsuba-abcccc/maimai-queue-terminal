# maimai Q 0.13.1 现场终端补丁

maimai Q 0.13.1 调整现场终端玩家资料库的编辑入口，让列表中的长昵称获得更多显示空间，并在进入具体资料后提前反映网页账户的终端编辑权限。管理后台继续使用独立版本 `0.13.0`，网站保持 `0.12.3`，QQ Bot 保持 `0.3.13`。

> 本版本仍处于 `0.x` 测试阶段。真实现场覆盖安装前应备份终端数据，并确认 APK 使用与现有正式安装相同的发布证书。

## 本次更新

- 资料库列表卡片移除右侧铅笔按钮，整行点击仍会进入玩家资料详情，昵称可使用原按钮占用的横向空间。
- 玩家资料详情增加带铅笔图标的“编辑玩家资料”按钮，并与“绑定网页账户”按钮处于同一操作行。
- 固定组合和认领登记流程中的玩家资料详情也提供相同编辑入口。
- 已绑定网页账户且关闭终端编辑权限时，编辑按钮会提前置灰；点击置灰按钮会说明需要由玩家在网页重新开放权限。
- 未绑定网页账户的旧资料不受 `terminalEditingAllowed` 历史默认值影响，仍可在现场终端正常编辑。
- 本地版移除不需要的 Android 联网权限；现场终端版和管理后台继续保留联网权限。

## 下载文件

- `maimai-Q-0.13.1-terminal-beta.apk`：连接自建服务端的现场终端版，不预置服务端地址或令牌。
- `maimai-Q-0.13.1-local-beta.apk`：完全离线版，不申请联网权限。
- `SHA256SUMS-0.13.1.txt`：两个 APK 的 SHA-256 校验值。

管理后台 APK 没有随本补丁重发。需要管理后台时继续使用 `v0.13.0` Release 中长期证书签名的 `maimai-Q-0.13.0-management.apk`。

## 安装与兼容

- 现场终端应用 ID 仍为 `com.abcccc.maimaiqueue`，版本为 `0.13.1`、构建号为 `67`，可覆盖使用相同长期发布证书签名的正式终端版本。
- 本地版应用 ID 为 `com.abcccc.maimaiqueue.local`，版本为 `0.13.1`、构建号为 `67`。
- 本补丁不修改数据库结构、队列 schema、队列算法、闭店逻辑、正常拖动全队列排序或需要先关闭登记的风险设置。
- 生产 API 的 `QUEUE_LATEST_TERMINAL_VERSION` 应更新为 `0.13.1`；网站和 Bot 的最新版本配置不要随终端版本改动。
