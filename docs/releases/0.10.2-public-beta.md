# maimai Q 0.10.2 公开测试版

maimai Q 0.10.2 是首个实际发布到 GitHub Releases 的完整公开测试版本。部署者可以使用自己的 Linux 主机、域名、HTTPS、数据库卷和 QQ Bot，不依赖项目维护者服务器。

> 本版本仍处于 `0.x` 测试阶段。用于真实现场前，请先完成备份、恢复和完整联调，并安排能够处理误操作与机台故障的现场人员。

## 本次更新

- 提供不含私人服务器地址或令牌的联网终端版、完全离线版和独立公开队列网站；补齐自建、更新、备份与回滚说明。
- 增加现场终端、队列网站和 QQ Bot 的版本状态；Bot 新增“查询人数”，终端与网站完善机台分组切换。
- 修复关闭同步、测试终端恢复和接管时的竞态，避免旧实例或旧命令重新影响当前权威队列。
- 修复网站线上登记与移动设备登记并发提交同一玩家时可能产生重复命令的问题。
- 修复历史系统日志错误携带机台字段导致整份快照同步失败；旧记录会自动迁移，上传前还会再次规范化。
- 服务端错误现在会精确指出错误代码、字段路径、事件序号、标题和登记编号，便于直接定位同步失败原因。
- 现有闭店收尾、轮换、暂缓一次、暂时离开、待签到、固定组合和共同游玩预览规则均未改变。

完整累计更新见[项目更新日志](https://github.com/tsuba-abcccc/maimai-queue-terminal/blob/v0.10.2/docs/update.md)，自建步骤见[公开测试版自建部署方案](https://github.com/tsuba-abcccc/maimai-queue-terminal/blob/v0.10.2/docs/public-beta-deployment.md)。

## 下载文件

- `maimai-Q-0.10.2-terminal-beta.apk`：连接自建服务端的现场终端版。没有预置地址或令牌，安装后由机厅管理员配置。
- `maimai-Q-0.10.2-local-beta.apk`：完全离线版，不申请联网权限，不提供网站或 Bot 同步。
- `public-site-0.10.2-beta.tar.gz`：独立公开队列页静态文件。
- `koishi-plugin-maimai-q-0.3.12.tgz`：Koishi 插件；本版本未改动插件代码，继续沿用 0.3.12。
- `SHA256SUMS-0.10.2.txt`：全部发布附件的 SHA-256 校验值。

两个 APK 均使用既有 maimai Q 长期发布证书签名。证书 SHA-256 指纹：

```text
daa2e919d2f8d956c0a93417aae601e6ec658edc5ae7c9673830c53f649ec925
```

首次安装或覆盖升级前必须核对附件 SHA-256。Debug 版和 Release 版签名不同，不能直接互相覆盖；已有 Debug 联调终端迁移前需要先保存数据并停止现场排队。

## 稳定支持范围

- 一个机厅对应一个独立 API 实例和 SQLite 数据卷。
- 同一队列只允许一台权威现场终端写入；备用终端只能在原终端离线后接管。
- Android 10 或更高版本。
- 服务端故障时现场终端仍能继续本地排队；网站、线上登记和 QQ Bot 会暂停。

多机厅必须使用相互隔离的 API、数据库、令牌和站点地址。多终端同时联动和正式多租户不属于本版本已经支持的能力。

## 更新方式

GitHub Releases 是唯一权威更新来源。本版本没有自动下载或自动安装；后续补丁会推进版本号并创建新的不可变 Tag，不覆盖现有附件。更新前必须备份 SQLite、`.env`、反向代理、Bot、网站目录和 APK，按 API、网站、Bot、终端的顺序更新。

可以在 GitHub 使用“Watch → Custom → Releases”接收通知，或订阅：

```text
https://github.com/tsuba-abcccc/maimai-queue-terminal/releases.atom
```

## 已知边界

- 当前不提供预构建 Docker 镜像，API 由部署者从固定 Tag 的 `cloud-server/` 构建。
- 版本信息只与服务端 `QUEUE_LATEST_*_VERSION` 配置比较，不会主动访问 GitHub。
- 网站不开放退出排队、暂缓一次、暂时离开、切换机台和修改偏好等高风险远程操作；这类操作继续由终端或已验证 QQ 的 Bot 完成。
- 测试版需要部署者自行承担现场联调、备份和恢复责任。
