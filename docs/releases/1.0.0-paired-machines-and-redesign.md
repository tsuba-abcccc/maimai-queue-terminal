# maimai Q 1.0.0 自动安排登记与界面重新设计

## 本版范围

- 现场终端和本地版：`1.0.0`，构建号 `73`。
- 管理 App：`1.0.0`，构建号 `69`。
- 队列网站：`1.0.0`。
- QQ Bot：`0.4.0`。Bot 继续单独编号。
- 服务端默认的“最新版本”同步改为以上版本。

协议版本仍为 schema `8`，新内容都是可以缺省的字段。

版本号由维护者决定（2026-11-26）。路线图原定的 `0.14.0`、`0.15.0`、`0.16.0` 和 `1.0.0` 顺延为 `1.1.0` 至 `1.4.0`，见 [`docs/roadmap.md`](../roadmap.md)。

## 主要变化

### 自动在两台机台之间安排登记

机厅可以在设置中添加一对机台（默认关闭）。玩家确认登记时，可以勾选“允许系统在当前机台和 机台 B 之间安排登记”。

- 另一机台能够更早安排游玩时，先在其等待顺序中显示预览。预览至少显示 12 分钟后，登记才会自动转至另一机台。开启排队通知的玩家会收到私信。
- 登记只有一份，按开始等待的先后安排，不会排到更早开始等待的登记前面。
- 固定组合、临时登记、处于延后状态或待签到的登记不参与安排。为已经在排队的登记开启后，要等这份登记游玩一轮才开始安排。
- 第一次开启时弹出说明，5 秒后才能关闭。
- 网站提供同样的勾选框，管理 App 可以设置一对机台。

详细规则见 [`docs/user-manual.md`](../user-manual.md) 的“自动在两台机台之间安排登记”，设计过程见 [`dual-machine-queue-plan.md`](dual-machine-queue-plan.md)。

### 延后这份登记：三种方式

登记菜单的“延后这份登记”提供暂缓一次、轮空一次和暂时离开三种方式，用并排的对照卡片说明区别。

- **轮空一次**（新增）：下一次轮到时移至队尾，计一次轮空，随后自动解除。轮空次数与暂时离开合计；接近上限时才特别提醒。
- **暂缓一次**：游玩一轮之前不能再次暂缓。
- **已签到、尚未游玩的线上登记**：不能延后，管理 App 除外。
- 尚未发生的状态写作“将暂缓一次”“将轮空一次”。
- 未到场弹窗改用同样的对照卡片。
- 网站和 QQ Bot 提供同样的三种方式和相同的原因说明。

### 等待时间估算

改为按每轮时长的可能范围反复推演：

- 已经登记的玩家看到偏早的时间，大约十次里有三次会更早轮到。
- 加入排队前看到的是居中的估计。
- 提到位置时，写出位置编号（如“位置 A5”）。

### 界面重新设计

- **整体**：按屏幕分辨率等比例放大，1080P 和 2K 屏幕上控件更大。
- **首页**：重新设计。
  - 反馈横幅占据标题区。
  - “加入排队”和“更多”放在右上角。
  - 单台机台的分组可以排成两行，分组栏显示各组的机台和登记数。
- **登记菜单和位置菜单**：按“谁来操作”分组：游玩方式、这份登记、由现场玩家报告、与现场不一致时。
- **分步流程**：加入排队、玩家资料创建与编辑、认领登记、与朋友共同游玩、首次设置，都改为左侧摘要、右侧当前步骤的两栏页面。
- **其他弹窗和设置页**：
  - “结束本轮”弹窗画出下一组进入游玩位置的玩家；
  - “更改游玩偏好”弹窗改用与加入排队相同的选项样式；
  - 设置中新增“首页分组”表。
- **字号和圆角**：按对照表统一。
- 规范见 [`docs/ui-guide.md`](../ui-guide.md)，各阶段记录见 [`ui-redesign-2026-11.md`](ui-redesign-2026-11.md) 和 [`type-radius-review-2026-11.md`](type-radius-review-2026-11.md)。

### 文案统一

终端、网站、QQ Bot 和服务端提示按同一份用词规范逐条审查并统一，例如“撤回至等待顺序”“自动移除”“转至”。服务端提示也补上了句号。规范见 [`docs/copywriting-guide.md`](../copywriting-guide.md)，审查记录见 [`copy-review-2026-11.md`](copy-review-2026-11.md)。

### 排队规则修正

- 组成固定组合不再改变其他登记的顺序。
- 处于游玩位置的登记，要先撤回至等待顺序，才能延后。
- 停止使用的机台仍显示队列和明显的“已停止使用”标记，只能退出排队或转至其他机台。
- 取消暂时离开后保留已轮空次数。
- 管理后台执行的操作不在终端留下撤销项。
- 已签到的线上登记第一次轮到时未到场，只能移除。
- 移除登记时记录由谁操作。
- 修复添加一对机台时闪退。

### 服务端

- 修复两类问题：
  - 联系信息指向已删除的玩家资料时，快照上传失败；
  - 几处编号或文字字段传入非字符串时，返回未处理的错误。
- 支持轮空一次、一对机台的设置和登记字段。
- 玩家资料表新增两列，服务启动时自动补上。

## 升级与部署

**先更新服务端，再更新终端。** 旧服务端会拒绝“不是暂时离开、却带有轮空次数”的登记（`非暂时离开登记不能包含轮空次数`），而新终端在轮空一次期间会上传轮空次数。只先更新终端，上传就会失败。网站和 QQ Bot 的轮空一次操作也需要新服务端。

更新终端前：

- 先读出设备上已装应用的签名证书，确认与长期发布证书一致，再覆盖安装，不要卸载重装；
- 不要在正在排队时更新。

## 保留事项

- **真机验收**：本版的界面只在 720p 模拟器上检查过，还没有在现场的真实设备上验收。
- **管理 App**：待处理命令列表与取消，以及未到场时为线上登记置灰，留到之后。
- **还没有处理的待办**：
  - 夜间关机后第二天不应沿用前一天的队列；
  - 终端关闭期间签到时限不应用尽；
  - 仅凭 QQ 号的线上登记的风险。
- **线上实例**：带有 `test_data` 标记，是否有意为之尚未确认。
- **之后的版本**：多终端联动、多机厅、游玩时间自动学习和公开部署版，分别在 `1.1.0` 至 `1.4.0`。
