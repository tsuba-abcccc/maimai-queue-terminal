# maimai Q 0.10.0 详细开发计划

## 版本目标

本版本把现有固定 1 至 4 台机台扩展为可添加、删除的 1 至 10 台机台，并加入机台分组和首页分页。机台仍使用 A 至 J 作为现场展示编号，所有队列规则、登记位置和玩家用语保持不变。

本版本不改变实体排卡板式的轮换算法，不实现多终端同步，也不提前加入机厅或账号体系。为 0.11.0 多终端联动预留稳定的机台及分组身份。

## 数据与身份

- `MachineId` 扩展为 A 至 J，只表示当前连续展示位置。
- 每台机台增加不会随重编号改变的内部稳定标识。删除机台后，后续机台的稳定标识、详情配置和运行状态一同前移。
- 稳定标识不作为玩家可见编号，也不能代替 A 至 J 出现在排队位置、Bot 指令或普通日志文案中。
- 每个机台分组拥有稳定标识、显示名称和固定顺序。每台机台必须属于且只属于一个分组，每个分组至少包含一台机台。
- 保存设置时规范化空分组、失效分组引用和失效默认分组；不能产生没有首页入口的机台。
- 旧版 1 至 4 台配置自动补充稳定标识，并全部归入默认分组。旧队列、玩家资料、登记编号和历史日志 ID 保持不变。

## 添加、删除与重编号

- 只能在关闭登记排队后添加或删除机台；至少保留一台，最多十台。
- 新机台只追加在末尾，获得下一个连续字母、新稳定标识和独立默认配置，默认加入当前分组。
- 删除任意机台前显示明确确认内容，包括被删除的机台和将发生的编号变化。
- 删除后按原顺序原子重编号。例如删除 B 后，原 C 至 J 依次变为 B 至 I。
- 被删除机台仍有登记或处于停止使用状态时拒绝删除。关闭登记通常已清空登记，但执行层仍再次校验。
- 未被删除机台的停止状态按稳定标识随配置移动，不能因字母变化转移给另一台物理机台。
- 添加、删除、重编号和容量修改都会递增风险配置修订号。旧修订下的远程命令必须拒绝，不能作用于新字母对应的机台。
- 分组、分组名称、备注、类型、服务器、版本和计划时间不改变队列身份；只有会改变机台目标或轮换结果的设置进入风险修订。

## 分组与首页

- 设置中可以新建分组、修改分组名称、把机台移入其他分组并选择本终端默认分组。
- 移走某分组最后一台机台时自动移除空分组；默认分组被移除时改为第一个有效分组。
- 首页按分组横向翻页，底部显示页码圆点和当前分组名称；只有一个分组时不显示多余分页提示。
- 当前分组只有一台机台时继续使用单机台居中布局；超过可用高度时仅在组内纵向滚动。
- 首页侧边动态区、总登记数、登记开放状态和全局操作始终覆盖全部机台，不因当前只显示一个分组而遗漏。
- 30 秒无操作返回首页时，动画切换到本终端默认分组，再把该分组内各队列平滑滚动到最左侧。
- 分组配置变化、恢复旧状态或当前页失效时，页面索引必须收敛到有效范围，不能显示空白页或越界崩溃。

## 多端与协议

- 公开同步协议升级，最多接收十台连续机台，并携带稳定机台标识、分组列表、机台所属分组和默认分组。
- 服务器严格校验机台字母连续、稳定标识唯一、分组标识唯一、每台机台引用有效分组，以及所有分组非空。
- 旧协议快照继续按单一默认分组读取；新服务器继续兼容旧终端 A 至 D 快照。
- 网站按分组提供切换入口，切换只改变显示，不改变估时、自我标记、线上登记或远程命令目标。
- QQ Bot 队列总览按分组排版，机台选择支持 A 至 J 及对应小写字母和唯一备注；命令仍提交当前展示字母和配置修订号。
- 事件、日志、通知、移动设备登记和网站登记使用相同机台上限，不得在任一端截断第五台之后的数据。

## 行为与迁移测试

- 覆盖 1、2、3、4、5、9、10 台机台的设置、保存、恢复、同步和选择布局。
- 覆盖删除 A、中间机台、末尾机台，以及连续多次添加和删除；核对配置、稳定标识、状态和字母映射。
- 覆盖删除唯一机台、添加第十一台、删除停止机台、登记开放时修改及远程命令处理中保存的拒绝路径。
- 覆盖单分组、多分组、移动最后一台、默认分组被移除、空分组规范化和旧设置迁移。
- 覆盖首页分页、默认页、单机台居中、组内滚动、30 秒复位和新登记定位到非当前分组。
- 覆盖十台各 20 份登记的云端边界、事件关联上限、快照大小、网站布局及 Bot A 至 J 输入。
- 继续运行既有队列核心长序列测试，证明新增配置不会改变轮换、暂缓一次、待签到、固定组合、共同游玩预览、撤销和跨机台转移结果。

## 发布门槛

- App、队列核心、云端和 Koishi 全部测试通过；Android Debug 与签名 Release APK 构建通过。
- 网站完成桌面、手机、浅色和深色主题视觉核对，十台及多分组情况下不存在溢出、错位或不可达操作。
- 完成旧版数据迁移、服务器先后升级、断网恢复、过期远程命令和关闭后重新开放行为测试。
- 更新 README、用户手册、同步协议、版本日志、GPL-3.0 许可证核对和玩家更新日志。
- 发布 GitHub 提交、`v0.10.0` Tag、Release 和签名安装包；前端变更同步部署网站并推送网站仓库。
