# 网站与终端的功能对照（2026-11-27）

维护者：“然后确保网页端和终端功能对齐。”原则见 `usability-review-2026-11.md` 第一部分：网站跟随终端的体验（入口、分组、步骤、用词、灰显原因）。

做法：只读对照。把玩家在终端上对自己的登记能做、能看到的逐项列出，再到网站上核对；每一条差异都读过两边的代码。操作者才用的功能（结束本轮、未到场、调整顺序、撤回、机台停止使用、设置、批量创建、认领、管理后台）和现场签到（“已到场”，有意只在终端）不算差异。QQ Bot 不在范围内。

账户对话框（`PlayerAccountDialog.vue`）和队列页的登记详情（`QueueStatusPanel.vue`）是同一套操作面板的两份实现，面板上的差异两处都有。

“状态”一列：**已对齐** = 本轮已改；**待定** = 需要维护者决定；**下一轮** = 方向明确，改动跨终端、服务端和网站三处。

## 二、网站有而终端没有，或说法不同

- 更改游玩偏好：网站要点“确认更改游玩偏好”，终端点一下就生效。有意如此（网站的更改要经过终端执行）。
- 退出排队的确认：网站多一句“游玩位置中的空缺不会自动由等待顺序中的下一组登记补入。”；终端有一句网站没有的“只有玩家本人可以退出排队。”（只对现场有意义）。
- 轮空接近上限的提醒：设置之后，网站在卡片和详情里显示；终端菜单只显示“将轮空一次·已轮空 N 次”。
- 转至的选择页：网站多一句关于仅能容纳一人的机台不能接收固定组合的说明，其中写“更改本次游玩偏好”，入口的名称是“更改游玩偏好”。
- 为他人创建线上登记（按 QQ）：终端只在“与朋友共同游玩”里为朋友创建登记。
- 本人登记卡片上暂时离开的说明：“第 4 次轮到时仍未取消暂时离开，登记会自动移除。”终端只在确认时说。

## 三、核对过、已经一致的

登记菜单的分组和入口；延后这份登记的三张卡片、确认和灰显原因；更改游玩偏好的选项文字；单人游玩的越过（勾选框、三种状态、“将越过”）；两台机台之间安排（勾选框、说明、首次 5 秒、预告的三种状态、预览）；转至的确认；退出排队的主文；等待时间的各种写法；位置和状态的标签；操作结果（网站原样显示终端的回答）。

## 四、没有覆盖

手机建档页和资料设置页；资料与通知两个标签；位置详情（估计之外）；首页横幅、日志页、机台详情；自动事件的通知标题；服务端自己写的拒绝语句；用户手册和文案规范的逐行对照；颜色和排版（需要在浏览器里看）。

## 五、对齐时的几处取舍（2026-11-28）

- 越过的说明和状态说明里，终端写“会在首页显示”“可以在位置菜单或……中取消”；网站没有首页和位置菜单，写作“会显示“将越过””“可以在“更改游玩偏好”中取消。”。
- 越过说明的入口：网站改为与两台机台之间安排的勾选框相同的问号（“查看说明”），与终端一致。
- 闭店提醒里可改选的机台：终端列出其他所有可以加入的机台，网站只列出不会晚于闭店的机台。
- 终端把另一机台的时间向下取整、本机台的时间向上取整后比较；网站每台机台只有服务端给出的一个数，直接比较。
- 一次确认里有多条命令时，结果横幅用第一条命令的标题；终端每条命令各有一条横幅。
- 子代理在浏览器里对着临时服务看过大部分页面；没有看的：深色模式、满 20 份登记的机台、队列页详情里的解除固定组合确认（与账户对话框同一段代码）、“暂缓一次”以外各操作的横幅标题。
