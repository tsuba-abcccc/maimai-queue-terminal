# maimai Q 玩家宣传文案

## 核心传播语

**队伍走到哪，心里都有数。**

maimai Q 是一套面向舞萌现场的玩家排队系统。现场登记，手机查看；顺序、预计等待、游玩偏好和离开状态，都能清楚确认。

现场部署也不需要额外购买成套排卡板、读卡器等外设。一台兼容的 Android 平板即可运行本地终端；网站和 QQ Bot 可以根据需要再接入。

## 群公告 / 首次发布

排队不用再全靠“记得前面还有谁”。

maimai Q 是一套面向舞萌现场的玩家排队系统。到店后，在终端完成登记，并选择单人游玩、允许他人加入或固定组合；等待时，可以在网页查看自己的队列位置和预计时间。临时有事，也可以按规则使用“暂缓一轮”或“暂时离开”，不用再靠口头传话。

添加 QQ Bot 好友后，还可以查询自己的状态，并接收与你有关的排队提醒。场地开放线上登记时，玩家可以从网页或 Bot 加入队列，但仍需按提示到现场终端完成签到。

它不是线上预约，也不会替任何人占位。所有安排仍以现场终端记录和场地规则为准。

部署不需要成套排卡外设。一台兼容的 Android 平板即可运行现场终端，网络功能可以按需要扩展。

少问一句“现在到谁了”，多一点时间安心打歌。

> 玩家自制排队工具，与游戏官方无关。具体功能以现场实际开放情况为准。

## 短版动态文案

到谁了？还要等多久？临时离开会不会过号？

maimai Q 把顺序、估时、游玩偏好和现场状态放进一条看得懂的队列里。现场登记，手机查看；规则照旧，信息更清楚。

不需要成套排卡外设，一台兼容的 Android 平板即可开始现场使用。

> 不是线上预约，现场安排仍以终端为准。

## 推荐发布顺序

1. 先发布主视觉与短版动态文案。
2. 第二张优先发布“实体排卡板逻辑”，用轮换前后对照解释系统最核心的特点。
3. 在同一条动态或群相册中依次发布日常使用、加入排队、游玩偏好、状态规则和特色功能。
4. 网站与 Bot 功能只在场地确实开放时发布。
5. 最后一张保留使用边界，避免玩家将线上登记理解成远程占位。

## 用词约定

- 对外统一使用“登记”“队列位置”“游玩位置”“暂缓一轮”“暂时离开”“签到”。
- 可以在解释中使用一次“拼机”，但按钮与规则名称仍写“允许他人加入”。
- 不使用“抢号”“预约成功”“保证轮到”等容易产生误解的表达。
- 不宣传“绝对实时”或“百分之百准确”；预计时间始终是基于当前队列状态的估算。
